**"LabVIEW Virtual Instruments Project Developing & Management"**
- **Author**: Gaoke Yang
- **ISBN**: 978-7-111-36804-5
- **Published by**: China Machine Press, Jan 1, 2012.

This book is mainly about the virtual instruments project developing and management technologies based on LabVIEW platform. It can be used as reference material for virtual instrument developers, also can be used as textbook or training material for university/college students.There are plenty of source code examples, templates and frameworks for virtual instruments applications to support your innovation.
