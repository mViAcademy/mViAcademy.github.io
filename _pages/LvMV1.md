**"Image Processing, Analysis and Machine Vision(based on LabVIEW)"**
- **Author**: Gaoke Yang
- **ISBN**: 987-7-302-49641-0
- **Published by**: Tsinghua University Press, Jun 1, 2018.<br>
This book is mainly about the image processing, analysis and machine vision technologies based on LabVIEW platform. It can be used as reference material for machine vision engineers, also can be used as textbook or training material for university/college students. There are plenty of source code examples, templates and frameworks to support your innovation. Online video courses are also available to shorter your learning curve.
